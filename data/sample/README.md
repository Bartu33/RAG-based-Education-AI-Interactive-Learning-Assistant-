# Sample Course Dataset (data/sample/)

This folder contains open-licensed course materials used as the shared baseline dataset for ingestion, chunking, retrieval, question generation, and hallucination evaluation.

## Included Courses (MIT OpenCourseWare)

1. **MIT 6.0001 — Introduction to Computer Science and Programming in Python**
   - Format: Lecture Slides (PDF)
   - Focus: Short bullet points, code snippets, introductory CS concepts.
2. **MIT 6.006 — Introduction to Algorithms**
   - Format: Lecture Notes (PDF)
   - Focus: Data structures, complexity analysis, formal algorithmic proofs.
